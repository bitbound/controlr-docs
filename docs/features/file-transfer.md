## Overview

Transfer files between your local machine and connected ControlR devices securely and efficiently.

## Features

- **Drag and drop** — Simple file upload via the web interface
- **Bidirectional** — Upload to or download from remote devices
- **Progress tracking** — Monitor transfer progress in real time
- **Resume support** — Interrupted transfers can be resumed

## Usage

1. Navigate to the **Files** section for the target device
2. Drag files into the upload area or use the upload button
3. Monitor progress in the transfer panel
