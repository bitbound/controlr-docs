## Overview

Chat provides real-time messaging between you and a connected device. It works across all supported platforms.

## Accessing Chat

1. Navigate to a device's page
2. Click **Chat** in the device access menu
3. Or go directly to `/device-access/chat?deviceId={id}`

## Usage

1. Click **Start Chat** to begin a new chat session
2. Type your message in the input field
3. Press Enter or click the send button to send
4. Toggle multiline mode for multi-paragraph messages
5. View message history from previous sessions

## Interface

| Area | Description |
|------|-------------|
| **Message List** | Shows all messages with sender name and timestamp |
| **Input Field** | Type messages here |
| **Send Button** | Send the current message |
| **Multiline Toggle** | Enable multiline input for longer messages |

## Connection States

| State | Description |
|-------|-------------|
| **Loading** | Connecting to the chat service |
| **Alert** | An error has occurred |
| **Session Select** | Waiting for the user to select a chat session |
| **Chat Active** | Chat session is active and messaging is available |
| **Unsupported OS** | The remote OS is not supported for chat |
