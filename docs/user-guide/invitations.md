## Overview

The Invitations page (`/invite`) lets you invite new users to join your tenant. You need the `TenantAdministrator` role to access this page.

## Inviting Users

1. Enter the user's email address
2. Click **Send Invitation**
3. An invitation link is generated and sent to the user's email

## Managing Invitations

The invitations page shows all pending invitations with:

| Column | Description |
|--------|-------------|
| **Email** | Email address the invitation was sent to |
| **Status** | Pending, Accepted, or Expired |
| **Created** | When the invitation was created |
| **Actions** | Delete or resend invitation |

| Action | Description |
|--------|-------------|
| **Search** | Filter invitations by email address |
| **Delete** | Cancel a pending invitation |
| **Resend** | Resend the invitation email |

## Accepting an Invitation

When a user receives an invitation email, they can:

1. Click the invitation link in the email
2. Go to the invitation page (`/invite-confirmation`)
3. Enter their email and choose a password
4. Join the tenant — they're redirected to the login page
