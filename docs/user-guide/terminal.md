## Overview

The Terminal provides remote shell access on any connected device. ControlR uses an embedded cross-platform PowerShell host, available on Windows, macOS, and Linux.

## Accessing the Terminal

1. Navigate to a device's page
2. Click **Terminal** in the device access menu (or go to `/device-access/terminal?deviceId={id}`)

## Features

| Feature | Description |
|---------|-------------|
| **PowerShell** | Cross-platform PowerShell (PowerShell Core) on all platforms |
| **Command Completions** | Tab-completion for commands, parameters, and file paths |
| **Multiline Input** | Toggle multiline mode for complex commands |
| **Keyboard Shortcuts** | Full keyboard integration |

## Usage

1. Type commands in the terminal input field
2. Press Enter to execute
3. Use Tab for command autocompletion
4. Toggle multiline mode for commands that span multiple lines
5. Copy/paste is fully supported

## Output Display

Terminal output displays scrollable command history. Scroll through the output history to review previous commands.
