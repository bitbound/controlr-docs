ControlR is a powerful, open-source remote control application for managing and controlling devices over a network. It provides a unified interface for remote access, file transfer, terminal management, and more.

## Why ControlR?

- **Cross-platform** — Works on Windows, macOS, and Linux
- **Real-time control** — Low-latency remote device management
- **Secure by default** — Encrypted communications and token-based authentication
- **Self-hosted** — Full control over your data with Docker deployment
- **Open source** — MIT licensed, community-driven
