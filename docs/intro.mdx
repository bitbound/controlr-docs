ControlR is a powerful, open-source remote control application for managing and controlling devices over a network. It offers a web-based interface for remote desktop, file transfer, terminal management, and device monitoring.

## Why ControlR?

- **Cross-platform:** Web dashboard works in any modern browser; agents run on Windows, macOS, and Linux
- **Real-time control:** Low-latency remote desktop with screen streaming and input forwarding
- **Secure by default:** Multi-tenant isolation, token-based authentication, and TLS-encrypted communications
- **Self-hosted:** Full control over your data with Docker deployment
- **Open source:** MIT licensed
